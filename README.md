# EchoShelf site

The public homepage and privacy policy for EchoShelf, a local-first audiobook player for Windows
and Android that syncs listening progress through each user's own Google Drive.

- Home: https://slurms602.github.io/echoshelf-site/
- Privacy policy: https://slurms602.github.io/echoshelf-site/privacy.html

Plain static HTML and CSS, served by GitHub Pages from the root of `main`. The source of truth is
the `site/` folder in the EchoShelf repository; copy changes here to publish them.

Questions about privacy? [Open an issue](https://github.com/Slurms602/echoshelf-site/issues).
